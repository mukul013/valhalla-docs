## How it works

- Share your referral code with friends.
- When they start using the bot, they are linked to you automatically.
- You earn **20% of the trading fees they pay to Valhalla**.
- Fees split automatically. No manual payouts.

Referrals are per account, not per wallet.

## Get your code

1. Run `/valhalla start` in any Discord server with the bot, or open **Referrals** on the website.
2. Your unique code appears. Copy it.
3. Give it to a friend before they first run the bot.
