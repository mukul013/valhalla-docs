Valhalla copies the positions of wallets you follow on Meteora, from your own Solana wallet.

| Feature | Status |
|---|---|
| DLMM copy trading | Open to everyone |
| Stop-loss, take-profit, auto-close above range, rug check | Open |
| Token filters, Jupiter Shield, token tax | Open |
| [DAMM](damm.md) | Beta |
| [Presets](presets.md) | Beta |
| [Multiple wallets](../account/wallets-and-multi-wallet.md) | Beta |
| [HawkFi wallets](hawkfi.md) | Supported |
