Valhalla copies the positions of wallets you follow on Meteora, from your own Solana wallet.

| Feature | Status |
|---|---|
| DLMM copy trading | Open to everyone |
| Stop-loss, take-profit, out-of-range auto-close, rug check | Open |
| Token filters, Jupiter Shield, token tax gate | Open |
| DAMM pools | [Beta](damm.md) |
| Presets | [Beta](presets.md) |
| Multiple wallets | [Beta](../account/wallets-and-multi-wallet.md) |
| HawkFi keeper wallets | [Supported](hawkfi.md) |
