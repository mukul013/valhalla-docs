Pick one path. The website is easier the first time.

## Before you start

- A Discord account or a Gmail address to sign in.
- A few SOL you can afford to lose (Meteora), or ETH on Robinhood Chain (beta).
- A referral code from a Valhalla member if you start from Discord.

## Option A: the website

1. Open the Valhalla website and click **Enter Valhalla**.
2. Sign in with Discord or Gmail. You land on the dashboard.
3. Open **Setup** in the left rail. It shows one checklist card per LP network.
4. On the **Meteora** card, create your wallet, then copy the wallet address.
5. Send SOL to that address from an exchange or another wallet.
6. Open **Copy trade** and follow your first wallet. See [Follow a wallet](../meteora/follow-a-wallet.md).

::shot[Setup checklist | /dashboard/setup with the Meteora card mid-progress and the Robinhood card showing its Beta badge | The Beta badge and the wallet step | quick-start-setup.png]

You should see the wallet balance on the Meteora overview, and your follow listed as active.

## Option B: the Discord bot

1. Optional: allow the bot to send you direct messages, so you get trade alerts and PnL images.
2. Join the community Discord.
3. In a channel that accepts bot commands, run `/valhalla start`. Enter your referral code when asked. This creates your wallet and profile.
4. Run `/valhalla export_keys` and set a PIN. See the [Security Guide](../safety/security-guide.md).
5. Run `/valhalla settings_dlmm` to follow a wallet and set filters and limits.
6. Run `/valhalla top_trade_wallets` if you need ideas for who to follow.

::shot[Discord start flow | The /valhalla start response showing the new wallet address and referral code, then the settings_dlmm panel | Wallet address (blur in real shots) and the Follow button | quick-start-discord.png]

:::warn
Before you follow any wallet, check its recent activity, the tokens it picks and how steady its profit is. Use [Wallet research](../help/wallet-research.md).
:::
